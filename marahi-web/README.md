# مراحي 🐪🐑🐐🐄 — نسخة الويب

موقع/تطبيق ويب **مستقل** لإدارة الحلال (إبل، غنم، ماعز، بقر)، يعمل **بدون إنترنت** ويخزّن كل البيانات **محلياً على جهازك** (داخل المتصفّح) — بلا سيرفر ولا حساب.

> دليل فرعي مستقل تماماً عن مشروع alaoufi.me. كل ملفاته داخل `marahi-web/` ولا علاقة له ببقية المستودع.

## التشغيل
- **مباشرة:** افتح ملف `index.html` في المتصفّح — يعمل فوراً.
- **كموقع (PWA):** ضعه على أي استضافة ثابتة (Vercel / GitHub Pages / Netlify) أو شغّل خادماً محلياً:
  ```bash
  cd marahi-web
  python3 -m http.server 8080
  # افتح http://localhost:8080
  ```
  عند فتحه عبر `http(s)` يُسجَّل Service Worker فيعمل **أوفلاين** بعد أول زيارة، ويمكن **تثبيته** على الجوال كتطبيق («أضف إلى الشاشة الرئيسية»).

## المزايا
- **سجل البهيمة:** النوع، رقم المراح، معرّف مرن (رقم / وسم / شريحة / اسم — مهم للإبل)، الجنس، الميلاد، اللون، الحالة، النسب، الملاحظات.
- **النسب التلقائي:** سجل الأم يعرض مواليدها («أنتجت: …»).
- **التلقيح والحمل:** حساب مدة الحمل وتاريخ الولادة المتوقع **تلقائياً** حسب النوع.
- **الولادات:** تسجيل المولود وربطه بالأم وإضافته كبهيمة جديدة.
- **التطعيمات:** تعريف الأنواع مرة واحدة + إعطاء تطعيم مع حساب انتهاء التحريم تلقائياً.
- **العلاجات:** نوع/اسم العلاج + التحريم + الإجراء مع حساب الانتهاء.
- **التنبيهات:** ولادة خلال ٧ أيام، انتهاء التحريم، مواعيد تطعيم.
- **البحث:** برقم / وسم / شريحة / اسم.
- **النسخ الاحتياطي:** تصدير JSON و Excel (CSV)، استعادة، ومشاركة عبر واتساب/البريد (Web Share).
- **عربي RTL** بالكامل، وواجهة جوال بشريط سفلي.

## التقنية
HTML + CSS + JavaScript صِرف (بدون أطر عمل ولا خطوة بناء). التخزين عبر `localStorage`، والعمل أوفلاين عبر Service Worker.

## الملفات
```
marahi-web/
├── index.html            هيكل الصفحة
├── app.css               التنسيقات
├── app.js                كل المنطق + التخزين المحلي
├── manifest.webmanifest  إعداد PWA
├── sw.js                 Service Worker (أوفلاين)
└── icon.svg              الأيقونة
```

## ملاحظة مهمة
البيانات محفوظة في متصفّح هذا الجهاز فقط. خذ **نسخة احتياطية** (من شاشة «النسخ الاحتياطي») بانتظام، خاصة قبل تغيير الجهاز أو مسح بيانات المتصفّح.
