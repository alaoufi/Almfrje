# المفارجة (almfrje) — نظام شجرة الأنساب وإدارة الفروع 🌳

تطبيق ويب **مستقل** لإدارة شجرة أنساب عائلة كبيرة: بحث فوري، استعراض الشجرة، عرض الذرية، إدارة الفروع، تقارير، وتصدير PDF — مع **استيراد لمرة واحدة** من ملف Excel (أو PDF) يمثّل الأجيال بالأعمدة.

> دليل فرعي مستقل تماماً عن بقية مشروع alaoufi.me. البيانات معزولة في جداول ببادئة `almfrje_` ليسهل فصلها/نقلها لاحقاً.

## البنية
- **الواجهة:** HTML + CSS + JavaScript صِرف (بلا أطر عمل ولا خطوة بناء) — ملفات ثابتة في `public/almfrje/`.
- **يُخدم على المسار:** `https://موقعك/almfrje` (عبر مشروع Next.js الحالي — يُنشر تلقائياً مع الموقع على Vercel).
- **الخادم/القاعدة:** Supabase (Postgres) — مصادقة + صلاحيات على مستوى الصفوف (RLS).
- **الاستيراد:** يتم في المتصفّح عبر `xlsx` (Excel/CSV) و `pdf.js` (PDF) — لا حاجة لكود خادم.

## كيف يفهم النظام ملف Excel؟
كل **عمود = جيل**:
- العمود الأقصى يميناً = **الأصل** (الجيل الأول).
- العمود التالي = أبناء الأصل (الجيل الثاني) — وكل واحد منهم يصبح **فرعاً رئيسياً**.
- بقية الأعمدة = الأجيال الأعمق.
- الأسماء المتتالية في نفس العمود = **إخوة** لنفس الأب في العمود السابق.

مثال (آل فراج):
```
فراج
└── سيف
    └── محمد
        └── الحميدي
            └── شامان
                └── سالم
                    ├── خالد ── (زياد، جهاد، ثامر)
                    ├── وليد ── (راكان، يزن)
                    └── حمود …
```
يحوّل المحرّك هذا التنسيق آلياً إلى علاقات أب/ابن حقيقية، ويحسب **الجيل** و**الفرع** لكل شخص.
> **الأدق للاستيراد: ملف `.xlsx`/`.csv`** (الأعمدة محفوظة). الـ PDF مدعوم بأفضل جهد (تحليل مواضع الأعمدة)، فراجِع المعاينة قبل الاعتماد.

## الإعداد — **تلقائي بالكامل** (لا تدخّل يدوي) ✅

المفارجة تشترك في **نفس قاعدة بيانات alaoufi.me** (Supabase)، وجداولها معزولة ببادئة `almfrje_`،
ويُنشأ مخططها **آلياً** ضمن منظومة الترقية الموحّدة `/api/migrate` — تماماً مثل «مراحي». لا حاجة
لمشروع Supabase منفصل ولا لتشغيل أي SQL يدوياً.

### ١) الإنشاء التلقائي للجداول (بلا أي زر)
أوّل ما يُفتح تطبيق `/almfrje` يستدعي **ذاتياً** نقطة `/api/almfrje-setup` التي تُنشئ كل
جداول `almfrje_*` ودوال الصلاحيات وسياسات RLS والمُشغّل دفعةً واحدة (تحتاج `SUPABASE_PAT`
في متغيّرات البيئة — وهو نفسه المستخدم لمراحي). كل الأوامر `IF NOT EXISTS`/`OR REPLACE`
فتُنفَّذ مراراً بأمان دون حذف بيانات. الإعداد يُقرأ آلياً عبر `/api/almfrje-config`
(`NEXT_PUBLIC_SUPABASE_URL` و `NEXT_PUBLIC_SUPABASE_ANON_KEY`).

> لا حاجة لفتح لوحة الإدارة ولا تشغيل `/api/migrate` يدوياً. (يبقى المخطط ضمن `/api/migrate`
> أيضاً كطريقة بديلة.) وملف `schema.sql` هنا **مرجعي فقط**.

### ٢) أول مستخدم = مدير تلقائياً
الدخول **برقم الجوال أو اسم المستخدم + رقم سري من ٤ أرقام** (لا بريد). من شاشة التطبيق اضغط
**حساب جديد** وأدخل بياناتك — **أوّل** من يسجّل يصبح **مديراً مفعّلاً تلقائياً** (والبقية زوّار
موقوفون يفعّلهم المدير). لا حاجة لأي SQL يدوي.

### ٣) الاستيراد لأول مرة
بعد دخولك كمدير: **المزيد → 📥 استيراد ملف Excel** → ارفع ملف العائلة (`.xlsx`/`.csv`/`.pdf`) →
عايِن النتيجة → **تنفيذ الاستيراد**.

### (اختياري) مجلّد التخزين للصور/الوثائق
Storage → **New bucket** → الاسم `almfrje` → **Public**. (إن لم تنشئه، استخدم روابط الصور المباشرة.)

## الأدوار
- **مدير النظام:** صلاحية كاملة على كل البيانات والفروع والإعدادات والاستيراد.
- **مسؤول فرع:** يرى ويدير **فرعه فقط** (يضيف/يعدّل أفراده، يرفع وثائق، يخرج تقارير) ولا يرى الفروع الأخرى — مفروض على مستوى قاعدة البيانات (RLS).
- **زائر:** استعراض وبحث، وصلاحيات إضافية (إضافة/تعديل/تصدير) يمنحها المدير.

## المزايا
لوحة تحكم بإحصاءات • بحث فوري وبحث متقدم (الاسم/الأب/الجد/الفرع/الجيل/المدينة/الحالة) • صفحة شخص بسلسلة النسب والأبناء والأحفاد والذرية والوثائق • عرض الذرية بإحصاءات • شجرة تفاعلية قابلة للتوسعة + عرض هرمي نصي قابل للطباعة + نموذج أعمدة شبيه Excel • إدارة الفروع ومسؤوليها • تقارير شخص/فرع/إحصائي • تصدير PDF (طباعة) و JSON/CSV • الوضع الليلي • عربي RTL بالكامل • سريع حتى مع عشرات الآلاف من الأسماء (فهرسة في المتصفّح).

## ملاحظة أمان
- لا تضع **service_role key** في الواجهة إطلاقاً — فقط `anon public`.
- كل صلاحيات القراءة/الكتابة مفروضة في قاعدة البيانات عبر RLS، فلا يمكن تجاوزها من المتصفّح.
